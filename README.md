# NOMEC Modern Website

## Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React

## Pages Included
- Home (Hero, Stats, About Preview, Programmes, Facilities, Testimonials, CTA)
- About (Mission, Vision, Core Values, Timeline, Leadership)
- Academics (Montessori, Departments, Exam Performance)
- Admissions (Process, Requirements, Dates, CTA)
- Campus Life (Houses, Facilities, Extracurriculars)
- Contact (Form, Contact Info, Social Links)
- Student Portal (Dashboard, Results, Timetable)
- Parent Portal (Overview, Wards, Fees)
- Teacher Portal (Dashboard, Classes, Result Entry)

## Key Features
- Cursor-tracking loading screen with interactive spinner
- Scroll-reveal animations on all sections
- Responsive navigation with mobile menu
- Animated counters and progress bars
- Glass morphism and gradient effects
- No em punctuation used throughout
- Formal, prestigious tone and accent

## Installation

    npm install

## Development

    npm run dev

Open http://localhost:3000

## Build for Production

    npm run build
